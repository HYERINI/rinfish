# 낚시섬 어항 구경 모드·물고기 생김새·희귀 어종 추가 설계

- 작성일: 2026-10-22
- 상위 기획: `docs/superpowers/specs/2026-10-12-fishing-island-design.md` 4장(물고기), 8장(어항)
- 범위: (1) 어항 구경 모드, (2) 어종마다 다른 생김새, (3) 희귀·에픽 어종 9종 추가
- 다음 작업(이 문서 범위 밖): 구역 해금, 미끼

## 1. 목표와 성공 기준

잡은 물고기를 "보는 재미"를 만든다. 지금은 어항이 작고 물고기가 점처럼 보이며, 여러 어종이 같은 모델을 같이 써서 구분이 안 된다.

성공 기준:
- 어항 패널에서 "크게 보기"를 누르면 화면 가득 큰 수조가 뜨고, 전시한 물고기가 크게 헤엄친다. 끌어서 돌리고 휠로 확대·축소할 수 있다.
- 물고기를 클릭하면 이름·희귀도·무게·설명 카드가 뜬다.
- 23종(기존 14 + 새 9) 모두 결과 카드·도감·어항·낚아 올린 장면에서 서로 구분된다.
- 새 9종은 각 구역 물고기 목록에 들어가 낚을 수 있다(동굴 어종은 구역 해금 전까지 실제로는 못 잡는다).

## 2. 어항 구경 모드

- 어항 패널 위쪽에 **🔍 크게 보기** 버튼. 누르면 새 모드 `aquariumView`로 바뀌고 전체 화면 보기가 뜬다.
- 보기 화면은 게임 캔버스와 별개의 전용 `<Canvas>`(꾸미기 미리보기와 같은 방식)로 그린다.
  - 큰 수조: 지금 어항 종류(기본·바다·민물·동굴)의 물 색·바닥·장식을 크게 다시 그린다. 확장 단계와 무관하게 화면에 꽉 차는 고정 크기.
  - 전시 중인 물고기마다 큰 크기로 헤엄친다. 경로·배고픔(바닥에 가라앉음)·먹이(수면으로 몰림) 규칙은 게임 속 어항과 같은 코드를 쓴다.
  - drei `OrbitControls`: 끌어서 돌리기, 휠로 확대·축소(범위 제한), 이동(pan)은 끈다.
  - 물고기 클릭 → 화면 아래에 카드(사진·이름·희귀도·무게·설명). 빈 곳 클릭이나 X로 닫는다.
  - 비어 있으면 가운데에 "아직 전시한 물고기가 없어요. 낚시해서 전시해 보세요" 안내.
  - 오른쪽 위 **닫기(ESC)** → 어항 패널로 돌아간다.
- 보기 화면이 열려 있는 동안 게임 시간은 흐른다(어항 배고픔·수입이 실시간으로 보이게). 꾸미기 화면과 달리 멈추지 않는다.
- 휠은 보기 화면 안에서만 쓰이고 게임 카메라 줌은 바뀌지 않는다(`canZoom`은 `aquariumView`를 막는다).
- 게임 속 작은 어항의 물고기 크기는 지금의 1.5배로 키운다.

## 3. 어종마다 다른 생김새

생김새 = **모델 + 색 + 크기 + 소품**.

- **모델**: 지금 7종(Quaternius CC0)에 더해, 조사로 찾은 CC0 물고기 모델을 추가해 어종에 가장 비슷한 모델을 고른다. 출처는 `public/models/CREDITS.md`에 적는다. CC-BY 등 출처 표기 의무가 있는 모델은 쓰지 않는다.
- **색**: 모델 재질에 색을 곱한다(선택). 금빛 잉어, 노란 장어처럼 이름과 맞게.
- **크기**: 어종별 몸길이 배율(작은 송사리 ~ 큰 참치). 낚아 올린 장면의 희귀도별 크기와 곱한다.
- **소품**: 머리에 붙는 작은 3D 소품. 기본 도형으로 만든다(외부 에셋 불필요). 모델마다 머리 위치·방향이 달라서 어종 데이터에 소품 위치 보정값을 둔다.

소품 목록(최소):

| 소품 | 쓰는 어종 |
|---|---|
| 선글라스 | 선글라스 고등어 |
| 안대 + 두건 | 해적 참치 |
| 금관 | 왕관 쓴 황금 잉어 |
| 작은 왕관 + 개구리 모자 | 개구리 왕자 잉어 |
| 동그란 안경 | 안경 박사 붕어 |
| 머리띠 | 근육 도미 |
| 수면 모자 | 잠꾸러기 메기왕 |
| 구명튜브 | 구조대 가자미 |
| 우주 헬멧 + 빛나는 초롱 | 우주비행사 아귀 |

반짝임(디스코 해파리 무지갯빛, 번개 장어 노란 빛)은 재질의 발광(emissive) 색으로 낸다.

- 생김새 정의는 `src/game/data/fishLooks.ts`(어종 id → 모델·색·크기·소품) 한곳에 둔다. 모델 경로 결정·소품 그리기는 scene 쪽이 맡는다.
- 정의가 없는 어종은 기본 모델로 그린다(새 어종을 데이터에 먼저 넣어도 깨지지 않게).
- 결과 카드·도감 사진(`fishThumbnail`)도 같은 생김새(색·소품 포함)로 그린다. 사진 캐시 키는 어종 id로 바꾼다.

## 8. 추가: 스터디원 물고기 9종과 확률 방식 (2026-10-22 요청)

### 8.1 확률: 희귀도 묶음 단위
- 지금은 어종마다 희귀도 가중치를 받아서, 같은 희귀도 어종이 많은 구역일수록 그 희귀도가 통째로 잘 나온다(암초 에픽 4종 → 세게 던지면 에픽 37%).
- 바꾼 규칙: 희귀도마다 가중치(세게 던지기 보너스, 구역 덮어쓰기 포함)를 한 묶음으로 계산하고, 그 구역의 같은 희귀도 어종끼리 똑같이 나눈다. 어종 수와 무관하게 구역마다 희귀도 비율이 유지된다.

### 8.2 생김새·도감 확장
- `FishLook.stretch?: [x, y, z]`: 몸 비율(두께·높이·길이). 마른 멸치, 동글동글, 길쭉한 몸.
- `FishLook.rotate?: [x, y, z]`: 모델 자체 방향 보정(서 있는 오징어 모델을 눕힌다).
- `FishLook.wobble?: number`: 헤엄칠 때 몸을 추가로 휘청거리게 하는 세기.
- 새 소품: 숟가락 두 개(spoons), 왕눈이 눈(googlyEyes, 크기 조절), 억울한 눈썹(sadBrows), 숫자(digits: '3', '31'), 다크서클(darkCircles), 가격표(priceTag), 털+뽀글 파마+집게핀(furPerm), 형님 세트(금목걸이·흉터 = bossChain, bossScar), 빵(bread), 할아버지 세트(흰 수염·돋보기안경·양머리 수건·지팡이 = grandpa), 바가지 머리(bowlCut). 한 어종이 소품 여러 개를 쓸 수 있다(`accessories: [...]`).
- `FishSpecies.trivia?: string`: 도감·결과 카드에 설명 아래 한 줄로 붙는 쓸데없는 스탯.
