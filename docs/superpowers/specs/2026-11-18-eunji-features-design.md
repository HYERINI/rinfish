# 은지 기능 옮기기 설계 (합치기 3단계)

> 1·2단계(초원 띄우기 + 배, `2026-11-17-meadow-boat-design.md`)로 은지 맵이 낚시섬 세계에 들어왔다. 3단계는 은지 게임(Room Sim, `f3c3808`)의 **게임 기능 전부**를 낚시섬 R3F 코드로 옮긴다. 사용자 결정(2026-11-18)을 그대로 따른다.
> 은지 기능 조사본: 은지 저장소 `src/*.js` 기준. 아래 줄 번호는 은지 저장소 기준.

## 목표와 성공 기준

- 하나의 게임 안에서 낚시섬 기능과 은지 기능을 같이 한다: 낮과 밤·취침, 배고픔, 가방·요리·먹기, 줍기, 문, 마을 상인, 동물 사냥, 무기·사격장·PvP.
- 캐릭터·카메라·저장·같이 하기 서버는 낚시섬 것 하나만 쓴다(은지 캐릭터·스킨·서버는 가져오지 않는다).
- 돈은 **코인** 하나, 체력도 하나.
- 같이 하기에서 시계·잠 투표·동물이 모두에게 같다.
- 기존 낚시섬 기능(낚시·상점·어항·구역 열기·배)은 그대로 동작한다.

## 3-1 시간과 생존

### 체력 합치기

- 저장값 `survival` 에 `hunger`(0~100) 를 더한다. `stamina` 는 이름만 그대로 두고 "체력"으로 쓴다(최대 100).
- 체력이 주는 곳: 낚시(던지기 2, 줄다리기 0.6/s, 지금 그대로), 배고픔 0 (1.5/s), 동물·PvP 피해(3-3·3-4).
- 체력이 차는 곳:
  - 음식(아래 표), 벤치 6/s(그대로).
  - **배고픔 60 초과일 때 0.8/s** (은지 `REGEN`). 지금의 "돌아다니면 0.3/s" 는 이것으로 바꾼다(배가 부르면 회복, 굶으면 회복 없음). 줄다리기 중·약화 중엔 회복하지 않는다(지금 규칙 유지).
  - 자는 동안 3/s (은지).
- 배고픔: `100/720` /s 로 준다(12분). 메뉴·꾸미기 화면에서는 멈춘다(지금 `PlayTimeTicker` 규칙). 먹으면 아래 표만큼 찬다.
- 상태와 결과:

| 상황 | 결과 |
|---|---|
| 낚시·줄다리기로 체력 0 (배고픔 > 0) | 지금처럼 약화 3분 → 회복 못 하면 **진료소** |
| 배고픔 0 | 화면 경고 "배고파요! 뭐라도 먹어야 해요" + 체력 1.5/s 감소. 약화 3분 유예는 없다(굶주림은 이미 1분 경고가 있다) |
| 배고픔 0 인 채로 체력 0 | **굶어 죽음 → 침대** |
| 동물·PvP 피해로 체력 0 | **죽음 → 침대** |

- 판정 순서: 체력이 0 이 되는 순간 원인을 본다. 배고픔 0 이거나 이번 프레임 피해가 동물·PvP 면 죽음(침대), 아니면 약화(진료소 경로). 순수 함수 `logic/survival.ts` 로 테스트한다.

### 음식 → 배고픔·체력

| 음식 | 체력 | 배고픔 |
|---|---|---|
| 은지 요리 (sate 2~6) | sate × 2 (은지 그대로) | sate × 8 (은지 그대로) |
| 낚시섬 김밥 / 컵라면 / 에너지 음료 | 지금 그대로 (25 / 45 / 70) | +30 / +50 / +10 |
| 낚시섬 미스터찜 요리 (7종) | 지금 그대로 | +60 (비밀 요리 +100) |

### 침대와 죽은 뒤

- 침대: 은지 침실 침대(`world.bedSpot`, 은지 (3.5, 3.6) → 세계 (196.5, -3.6)). E "잠자기".
- 혼자: 화면이 1초 어두워졌다가 다음 날 06:00, 체력 100, 배고픔 −15(최소 10). 은지 그대로.
- 같이: 잠 투표. 침대에서 E → "잠자는 중 (n/필요 수)" 화면 + "일어나기" 버튼. 서버가 방 인원의 절반(올림) 이상이 자면 모두 아침. 맞으면 깬다.
- 죽음(침대 경로): 화면이 1.6초 어두워졌다 1.4초 머문 뒤 침대 옆(은지 (2.2, 2.4) → 세계 (197.8, -2.4))에서 깨어난다. 체력 100, 배고픔 60. 혼자면 다음 날 06:00. 같이면 시간 그대로. 동물은 진정한다. 가방·코인은 그대로.
- 진료소 경로는 지금 그대로.
- 배 타는 중 죽음: 진료소 경로와 같이 배를 끝내고(`requestTeleport` 가 이미 배를 끝낸다) 침대로 옮긴다.

### 낮과 밤

- 시계: 은지 `DayNight` (하루 480초, `t` 0 = 06:00). 지금 정오 고정을 푼다.
  - 혼자: 내 화면이 시계를 돌린다. 저장값에 `{t, day}` 를 더한다(다시 들어오면 이어서).
  - 같이: 서버 시계를 따른다(아래 "서버"). 저장된 혼자 시계는 건드리지 않는다.
- 빛·하늘: 은지 `update`·`skyFor` 그대로. 배경색과 바다 `uSky`·햇빛 방향을 매 프레임 하늘색에 맞춘다. 실내/실외 구분(은지 `roomAt`)으로 실내 배경을 바꾼다.
- 안개: 밤에도 섬이 흐려지지 않게 1·2단계처럼 끈다(은지 안개 값은 쓰지 않는다).
- 가로등: 마을 가로등 4개는 밤에만 켠다(1·2단계에서 숨겨 둔 것을 살린다). **빛 개수를 처음부터 같게** 두는 1·2단계 원칙은 지킨다: 낮엔 세기 0, 밤엔 은지 값.
- 밤의 낚시섬: 선착장 끝과 상점가에 등불 두 개(빛 2개, 밤에만 세기). 방 조명 4개 + 가로등 4개 + 섬 2개 = 빛 10개. 폰(품질 low)에서는 방 조명을 플레이어가 그 방 안에 있을 때만 켠다(세기만 바꿔 빛 개수는 그대로).
- 음악: 밤엔 조용한 곡(`calm`)으로 바꾼다(`logic/music.ts`).
- HUD: 왼쪽 위 코인 줄 옆에 "☀️ 3일차 14:20" (은지 `timeText`).

### 서버 (rinfish-rooms)

- 방 상태에 시계 기준점을 저장한다: `ctx.storage` 의 `clock = { epoch: ms, day0: number }`. 시각은 저장 없이 계산한다: `elapsed = (now − epoch)/1000`, `day = day0 + floor(elapsed/480)`, `tm = elapsed mod 480`. 그래서 틱 없이도 시계가 맞다.
- 보내는 것: `welcome` 에 `time {tm, day}` 를 더하고, 아침이 되면 `morning {day}` 를 모두에게. 클라이언트는 받은 값으로 `DayNight.sync` 하고 그 사이는 스스로 돌린다. 시계 확인용으로 30초마다 `time` 을 보낸다(아래 alarm).
- 잠 투표: 소켓 attachment 에 `sleeping` 을 둔다. `sleep {on}` 을 받으면 바꾸고 `sleepers {n, need}` 를 모두에게. `n ≥ need` 면 epoch 를 "지금 = 다음 날 06:00" 으로 옮겨 저장하고 `morning` 을 보낸다. 사람이 나가면 다시 센다.
- alarm: 방에 사람이 있는 동안만 다시 건다. 3-1 에서는 30초(시계 확인), 3-3 에서 동물 때문에 200ms 로 바뀐다. 마지막 사람이 나가면 alarm 을 지운다(잠들어 비용이 들지 않는다).
- 메시지 추가는 선택 필드·새 종류만 쓴다. 옛 클라이언트는 모르는 종류를 버린다(`parseServerMsg` 가 null). `NET.protocolVersion` 은 그대로 1.
- 배포 순서: 서버 먼저.

## 3-2 도구 칸·가방·요리·상인

### 도구 칸 (핫바)

- 화면 아래 가운데 9칸. 1 = 낚싯대(미끼 수를 탄약처럼 칸에 표시), 2 = 주먹, 3 = 칼, 4~7 = 총(3-4 에서 채움). 3-2 에서는 1~3 만 있다.
- 지금 들고 있는 도구(`equipped`)는 세션 상태. 저장은 하지 않는다(다시 들어오면 낚싯대).
- 낚싯대는 들고 있을 때만 보인다(`rodVisible` 에 조건 추가). 물가에서 E "낚시하기" 를 누르면 **저절로 낚싯대로 바꿔** 시작한다(번거롭지 않게).
- X: 손에 든 것 넣기(빈손).
- 같이 하기: `NetState` 에 선택 필드 `tool` 을 더해 남이 든 도구를 그린다(`boat` 와 같은 방식).
- 폰: 아래 가운데 도구 칸을 눌러 바꾼다.

### 감정 표현 → T 바퀴, 큰 지도 → Tab

- T 를 누르고 있는 동안 화면 가운데 감정 표현 5개 바퀴, 마우스 방향(또는 숫자 1~5)으로 고르고 떼면 실행. 폰은 지금 😀 버튼 그대로.
- Tab: 큰 지도 열고 닫기(1·2단계의 `map` 모드 그대로 연다).

### 가방 (I)

- 저장값에 `items: Record<ItemId, number>` 를 더한다. `ItemId` = 은지 `ITEMS` 22종(고기·뼈·지방·달걀·호박·버섯·요리 13종). 은지 `Inventory` 규칙(태그 재료는 가장 많이 가진 것부터)을 순수 함수로 옮긴다.
- 가방 화면: 지금 키오스크(`Kiosk`) 모양을 쓴다. 탭: "가방"(은지 아이템 + 낚시섬 간식), "요리법"(은지 13가지). 물고기 가방은 지금 판매함 그대로(섞지 않는다).
- 아이콘은 은지처럼 이모지.
- 칸 수 제한 없음(은지 36칸 대신 종류별 개수).

### 먹기 (F)

- F: 은지 `eatBest` (배고픔을 가장 많이 채우는 것부터). 가방에서 눌러 먹기도 된다.
- 먹는 모습은 지금 먹기 동작(`pressEat`, 손에 든 음식, "냠냠") 그대로. 은지 요리를 `FoodId` 에 더하고, 손에 든 음식은 이모지 판(스프라이트)으로 그린다. 같이 하기 `FOOD_IDS` 에도 더한다.

### 요리 (부엌 가스레인지)

- 은지 부엌 가스레인지(`world.stove`)에서 E → 가방 "요리법" 탭이 열리고 재료가 있으면 "요리하기". 요리 시간(은지 `time` 초) 동안 HUD 에 "요리 중… 3초" → 끝나면 가방에 요리 추가. 미스터찜 요리 연출과는 별개(그대로 둔다).

### 줍기·문

- 버섯 18개·호박 4개(은지 `outdoor.pickups`): E "버섯 따기" → 숨겼다가 120초(호박 90초) 뒤 다시 보인다. 내 화면만(같이 하기 동기화 없음, 은지 그대로).
- 문 4개: E 로 여닫기. 문 충돌체는 문 판의 상자를 은지 좌표로 다시 재서(1·2단계 원칙: 세계 행렬이 아니라 은지 그룹 기준) Rapier 상자를 바꾼다. 문 상태는 저장(은지처럼). 같이 하기 동기화 없음.

### 마을 상인과 가격 (코인)

- 상인 3곳: 정육점(46, 11.5) · 잡화점(52, 11.5) · 농산물 가게(58, 11.5) (은지 좌표). 사람 모양은 은지 모델(21MB) 대신 **낚시섬 캐릭터 프리셋**으로 노점 뒤에 세운다.

- 가격(은지 값 약 2배, 사용자 원칙):

## 3-3 동물과 사냥

### 공유 시뮬레이션

- 은지 `animals.js` 의 상태 기계(idle/walk/flee/attack/dead)를 **순수 TS** `logic/animalSim.ts` 로 옮긴다. 입력: 동물 목록, 플레이어 위치 목록(+ 실내 여부), dt, 난수. 출력: 새 목록 + 사건(공격·죽음·다시 나타남). 그래픽 코드가 없어서 서버와 클라이언트가 같이 쓴다.
- 동물 7종 수치·마릿수 12·다시 나타남 25초·들판 구역은 은지 그대로(`ANIMAL_ZONE` 은 은지 좌표 → 세계 변환).
- 공격은 맞은 동물만, 공격 대상은 때린 사람. 실내(은지 집 방들)에 있으면 포기한다.
- 혼자: 내 화면이 `animalSim` 을 돌린다(저장 안 함, 은지 그대로).
- 같이: 서버 alarm 200ms(5Hz)에서 `animalSim` 을 돌리고 `animals {list}` 를 보낸다(위치·방향·상태·체력, 소수 둘째 자리). 클라이언트는 다른 사람처럼 0.25초 늦게 이어 그린다. 방이 비면 동물 상태는 버린다(다음 사람이 들어오면 새로).

### 그리기

- 모델: 은지 `models/pets/*.glb` (956KB, Kenney Cube Pets, CC0) 를 `public/meadow/models/pets/` 로. 동물마다 `SkeletonUtils.clone` + 애니메이션(idle/walk/run/eat).
- 맞으면 빨갛게 번쩍, 죽으면 0.5초 넘어지고 1.4초 뒤 사라짐(은지 그대로).

### 사냥과 전리품

- 주먹(피해 1, 거리 1.3)·칼(베기 1 / 찌르기 2, 거리 1.8 / 2.3). 은지 공격 시간표(휘두른 뒤 맞는 순간) 그대로.
- 명중 판정: 휘두르는 쪽 화면에서 광선(Rapier ray 로 벽에 막히면 안 맞음) → 동물 판정 원.
  - 혼자: 바로 `animalSim.hit`.
  - 같이: `animalHit {id, dmg}` 를 서버로. 서버가 거리·쿨다운(주먹 300ms·칼 400ms·찌르기 700ms) 검사 후 체력을 깎고, 죽으면 `rollDrops` 로 전리품을 정해 **잡은 사람에게만** `loot {items}`, 모두에게 `animals` 로 쓰러짐을 알린다.
- 전리품은 바닥에 떠서 도는 물건(은지 `makeItemMesh`)으로 떨어지고, 가까이 가서 E(1.6m)로 줍는다 → 가방. 같이 하기에서는 잡은 사람 화면에만 보인다.
- 동물이 때리면: 혼자는 바로 피해, 같이는 서버가 `hurt {dmg, by:'animal'}` 를 그 사람에게.

## 3-4 총·사격장·PvP

### 총

- 은지 `WEAPONS` 수치 그대로(권총·소총·산탄총·저격총). 탄창·예비 탄약은 저장. 예비 탄약은 잡화점에서 산다(3-2 가격표).
- 모양: 은지 `buildWeaponModel`(기본 도형) 을 가져와 3인칭은 우리 캐릭터 손(`gripPosition`)에, 1인칭은 카메라에 붙인다.
- 쏘기: 화면 가운데에서 광선. 맞는 대상 = 동물(3-3) · 다른 사람(PvP) · 사격장 표적 · 벽(총알 자국). 벽은 Rapier ray, 나머지는 판정 원/상자 목록. 은지 반동·퍼짐·연사 수치 그대로.
- 소리: 은지 `audio.js` (WebAudio 합성, 파일 없음) 를 가져와 우리 효과음 음량 설정을 따르게 한다.
- 같이 하기: `shot {o, d, w}` 를 보내 남의 총알 궤적을 그린다(은지 그대로, 판정 없음). 들고 있는 무기는 3-2 의 `tool` 필드.

### 1인칭·조준경

- V: 1인칭/3인칭. 1인칭은 내 캐릭터를 숨기고 카메라를 눈높이에, 무기를 화면에 붙인다.
- 조준(오른쪽 누르기): 소총·저격총은 은지처럼 조준경 화면(배율 2단계, 휠로 바꿈). 3인칭에서 조준하면 그동안 1인칭(은지 그대로).
- 낚시 중·배 탈 때·패널이 열려 있을 땐 쏘지 않는다.

### 사격장

- 은지 `range.js` 를 vendor 로 가져와 사격장 방(1·2단계에서 빈 방으로 남긴 곳)에 표적·사대·무기 선반을 세운다. 무기 선반 E → 무기 고르기(도구 칸에 넣기). G → 60초 연습 게임(점수 최고 기록 저장).

### PvP

- 은지 그대로: 쏜 사람 화면이 명중을 판정해 `pvpHit {target, weapon, n}` 를 서버로. 서버가 무기 피해표(권총 20 · 소총 14 · 산탄 9×n≤8 · 저격 70 · 칼 15 · 찌르기 30 · 주먹 5)와 무기별 쿨다운을 검사하고 맞은 사람에게만 `hurt {dmg, by:'pvp', from}`. 죽으면 `died {by}` → 모두에게 "A 님이 B 님을 쓰러뜨렸어요".
- PvP 로 죽으면 침대 경로(시간 그대로). 같은 편 구분 없음(은지 그대로).
- 남의 몸 판정: 다른 사람마다 보이지 않는 캡슐(반지름 0.32, 높이 1.3).
- 이름표 아래 체력 막대(`NetState` 선택 필드 `hp`).

### 폰

- 은지 `touch.js` 처럼: 쏘기(끌면 시점 돌리기) · 조준 · 장전 · 무기 바꾸기 버튼, 위쪽 가방·지도. 낚싯대를 들고 있으면 쏘기 버튼 대신 지금 낚시 버튼.
