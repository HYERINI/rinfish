# 낚시섬 캐릭터 꾸미기·벤치 앉기·스크롤 줌 설계

- 작성일: 2026-10-21
- 상위 기획: `docs/superpowers/specs/2026-10-12-fishing-island-design.md` 11장(캐릭터)을 확장한다. 11장의 "종류 선택 + 색상 변경"을 "성별·피부·머리·옷·키·몸 부위 크기를 자유롭게 고르는 꾸미기"로 넓히고, 15장(2차)의 "캐릭터 파츠 장착" 중 옷 갈아입기를 앞당긴다.
- 범위: 캐릭터 꾸미기(만들기·옷장), 벤치에 실제로 앉기, 마우스 휠 줌

## 1. 목표와 성공 기준

스터디원들이 각자 자기 낚시꾼을 만들어 노는 재미를 준다. 생김새는 사람 비율을 지키고, 웃음은 동작과 과장된 비율로 낸다.

성공 기준:
- 처음 시작하면 캐릭터 꾸미기 화면이 뜨고, 고른 모습이 저장되어 다시 들어와도 유지된다.
- 선착장 옷장에서 언제든 모습을 바꿀 수 있다.
- 성별, 피부색, 머리 모양·머리색, 수염(남자), 윗옷·바지·신발·후드, 옷 색, 키, 몸 부위별 크기(머리·어깨·가슴·배·팔·다리)를 바꿀 수 있다.
- 남녀 모두 기존 낚시 반응 연출(걷기·조준·끌려가기·춤·벌러덩·시무룩)이 그대로 나온다.
- 벤치에서 E를 누르면 바다를 보고 실제로 앉고, 앉아 있는 동안 체력이 찬다.
- 마우스 휠로 카메라를 가까이·멀리 할 수 있다.

## 2. 에셋

모두 Quaternius 무료(Standard) CC0 팩. 출처는 `public/models/CREDITS.md`에 적는다.

| 팩 | 쓰는 것 |
|---|---|
| Universal Base Characters | 남/녀 몸(머리 포함), 눈, 눈썹, 머리 모양 5종(SimpleParted, Buzzed, Long, Buns, BuzzedFemale), 수염 1종 |
| Modular Character Outfits - Fantasy | 농부(Peasant), 레인저(Ranger) 옷. 성별별로 팔·몸통·다리·신발 부위가 나뉘어 있고, 레인저는 후드·벨트·팔찌·어깨받이가 더 있다. 옷 색 버전 2개(기본, 변형) |
| Universal Animation Library | 기존 10개 클립 + 앉기 3개(Sitting_Enter, Sitting_Idle_Loop, Sitting_Exit) |

조사로 확인한 제약:
- 남녀 뼈대는 이름은 같지만 길이가 다르다(최대 약 10cm). **성별마다 파일을 따로** 만든다: `public/models/characters/male.glb`, `female.glb`.
- 같은 성별 안에서는 몸·옷·머리가 같은 뼈대에 붙어 있어서, 모든 부위를 한 파일에 넣고 **보이기/숨기기로 갈아 끼울 수 있다**.
- 옷은 다른 성별 몸에 맞지 않는다. 옷 목록은 성별별로 따로 둔다.
- 몸 전체를 옷 아래에 두면 옷을 뚫고 나온다. 몸은 머리·목 부분만 남기고 옷이 덮는 부분은 잘라 낸다(기존 fisherman.glb 방식). 맨손은 옷의 팔 부위에 들어 있다.
- 피부는 구릿빛 텍스처라 색을 곱하면 어두워지기만 한다. **만들 때 피부 텍스처를 밝게(거의 흰색 쪽으로) 바꿔 두고**, 게임에서 피부색을 곱해서 밝은 피부부터 어두운 피부까지 낸다.
- 애니메이션 클립의 크기(scale) 트랙과, 골반을 뺀 이동(translation) 트랙은 지운다. 남겨 두면 매 프레임 뼈 크기를 1로 되돌려 키·몸 크기 조절이 안 먹고, 팔다리 길이가 틀어진다.
- 텍스처는 1024 jpg로 줄이고 노멀·러프니스 맵은 뺀다. 파일 하나 2~3MB가 목표.

**만드는 스크립트를 저장소에 남긴다**: `tools/build-characters/`(팩 받기 + 합치기 + 다듬기). 이전 fisherman.glb는 스크립트가 사라져 다시 만들 수 없었다. 원본 팩 zip은 커밋하지 않는다. 스크립트 의존성(gltf-transform 등)은 게임 의존성과 섞이지 않게 `tools/build-characters/package.json`에 따로 둔다.

기존 `fisherman.glb`는 새 `male.glb` + "어부 할아버지" 기본 꾸밈으로 대체하고 지운다.

## 3. 꾸미기 항목

`CharacterLook` (저장되는 값):

| 항목 | 값 | 비고 |
|---|---|---|
| gender | `'male' \| 'female'` | 바꾸면 그 성별에 없는 부위는 같은 종류의 기본값으로 바뀐다 |
| skinColor | `#rrggbb` | 견본 8색 + 직접 고르기 |
| hair | 머리 모양 id 또는 `'none'` | 성별별 목록. 남: SimpleParted, Buzzed, Long. 여: Long, Buns, BuzzedFemale (Long은 공용으로 쓸 수 있는지 만들 때 확인, 안 맞으면 성별별로 나눈다) |
| hairColor | `#rrggbb` | 견본 10색 + 직접 고르기 |
| beard | boolean | 남자만. 머리색과 같은 색 |
| top | `'peasant' \| 'ranger'` | 팔 + 몸통 (+ 레인저는 벨트·팔찌·어깨받이) |
| bottom | `'peasant' \| 'ranger'` | 다리 |
| shoes | `'peasant' \| 'ranger'` | 신발 |
| hood | boolean | 레인저 후드. 쓰면 머리카락은 숨긴다 |
| outfitColor | `'base' \| 'alt'` | 옷 텍스처 색 버전 |
| height | 0.75 ~ 1.3 | 전체 키. 루트 뼈 균일 배율. 발은 땅에 붙어 있다 |
| body | 부위별 배율 묶음 (아래 표) | 몸을 부위마다 따로 늘리고 줄인다 |

`body` 부위별 슬라이더 (사용자 요청: 체형은 마름·통통 하나가 아니라 부위마다 자유롭게):

| 슬라이더 | 범위 | 움직이는 뼈 |
|---|---|---|
| 머리 크기 | 0.7 ~ 1.6 | Head 균일 배율 |
| 어깨 너비 | 0.7 ~ 1.5 | clavicle 좌우 위치 벌리기 + spine_03 좌우 배율 |
| 가슴·등 두께 | 0.7 ~ 1.6 | spine_02·spine_03 좌우·앞뒤 배율 |
| 배 | 0.7 ~ 1.8 | spine_01·pelvis 좌우·앞뒤 배율 |
| 팔 굵기 | 0.6 ~ 1.8 | upperarm·lowerarm 굵기 방향 배율 |
| 팔 길이 | 0.8 ~ 1.3 | upperarm·lowerarm 길이 방향 배율 |
| 다리 굵기 | 0.6 ~ 1.8 | thigh·calf 굵기 방향 배율 |
| 다리 길이 | 0.8 ~ 1.3 | thigh·calf 길이 방향 배율. 길어진 만큼 몸 전체를 올려 발이 땅에 닿게 한다 |

- 부모 뼈 배율이 자식(손·발·머리)까지 번지지 않게, 굵기만 바꾼 부위의 자식 뼈에서는 배율을 되돌린다. 손 크기와 발 크기는 그대로 유지된다.
- 팔 길이를 바꾸면 손 위치가 달라지지만, 낚싯대는 손뼈를 따라가므로 그대로 쥔다.
- 극단값에서는 옷이 늘어나 보이거나 동작이 조금 어색할 수 있다. 웃긴 비율을 허용하는 쪽으로 범위를 잡고, 화면 확인 후 범위를 조정한다.
- 꾸미기 화면에 "몸 부위 초기화" 버튼을 둔다.

- 범위 밖이거나 없는 부위가 저장돼 있으면 불러올 때 기본값으로 고친다.
- 숫자 범위, 견본 색, 부위 목록, 기본 꾸밈은 모두 `src/game/data/`에 둔다.
- 키가 달라도 물리 충돌체(캡슐) 크기는 그대로 둔다(작은 캐릭터가 문을 빠져나가는 일 방지). 낚싯대는 손뼈를 따라가므로 키에 맞춰 따라온다.

기본 꾸밈(프리셋):
- **어부 할아버지**: 남, 회색 SimpleParted 머리, 수염, 농부 옷, 지금 모습 그대로
- **어부 아가씨**: 여, 갈색 Buns 머리, 농부 옷
- **레인저**: 남/녀 각각 레인저 옷 + 후드

**랜덤** 버튼은 성별·부위·색·키·몸 부위 크기를 무작위로 고른다(크기는 범위 안에서, 극단값은 덜 나오게).

## 4. 화면 흐름

- 저장된 모습이 없으면(처음 시작, 또는 이 기능 이전의 저장본) 게임 시작 시 꾸미기 화면이 뜬다. 이전 저장본은 "어부 할아버지"가 미리 골라진 상태로 뜬다. 처음 시작하는 사람은 "어부 할아버지"로 시작하고 원하는 대로 바꾼다.
- 선착장에 **옷장**(Kenney 가구 에셋 또는 단순 도형)을 두고, E로 꾸미기 화면을 연다(새 상호작용 대상 `wardrobe`, 새 모드 `wardrobe`).
- 꾸미기 화면:
  - 가운데에 미리보기 캐릭터가 천천히 돈다(가벼운 전용 Canvas, 드래그로 돌리기).
  - 옆 패널에 항목별 선택(버튼·견본 색·슬라이더).
  - 아래에 기본 꾸밈 버튼들, 랜덤, **완료**(저장하고 닫기), **취소**(옷장에서 연 경우만. 바꾸기 전 모습으로 되돌린다).
  - 첫 생성 화면에는 취소가 없다(ESC도 닫지 않는다).
- 꾸미기 화면이 열려 있는 동안 게임 시간은 멈춘다(ESC 메뉴와 같이 tick을 건너뛴다).

## 5. 캐릭터 구조

- `PlayerModel`은 `look`을 받아 해당 성별 파일을 불러오고, 매번 복제한 뒤:
  1. 부위 메시를 이름으로 찾아 `visible`을 켜고 끈다
  2. 피부 재질(몸·손), 머리카락 재질에 색을 곱한다
  3. 옷 텍스처를 색 버전에 맞게 바꾼다
  4. 루트 뼈 배율(키), 부위별 뼈 배율(몸)을 매 프레임 애니메이션 뒤에 적용한다
- 기존의 자세 섞기, 상체 젖힘, 손 위치 읽기는 그대로 두고 남녀 모두에 쓴다. 클립 이름 표는 남녀가 같다.
- 꾸미기 미리보기와 게임 속 플레이어가 같은 "모습 적용" 함수를 쓴다.
- 성별을 바꾸면 다른 파일을 불러와야 하므로, 두 파일 모두 미리 받아 둔다.

## 6. 벤치에 앉기

- 벤치에서 E → `rest` 모드(기존). 플레이어를 벤치 자리로 옮기고 바다 쪽(+z)을 보게 한 뒤, Sitting_Enter → Sitting_Idle_Loop를 재생한다.
- E/ESC로 일어나면 Sitting_Exit를 재생한 뒤 서 있기로 돌아간다. 일어나는 도중에 이동 키를 누르면 바로 걷기로 섞여도 된다.
- 엉덩이가 벤치 면에 닿도록 앉는 위치 높이를 맞춘다(클립의 골반 높이 기준, 화면으로 확인).
- 앉아 있는 동안 체력 회복은 기존 규칙 그대로.

## 7. 스크롤 줌

- 마우스 휠로 카메라 거리를 바꾼다. 범위 1.5 ~ 18(기본 10). (2026-10-22 변경: 최소 4 → 1.5, 얼굴이 보일 만큼)
- 거리 6 이상에선 카메라가 시선 높이(키의 0.55)보다 거리 × 0.7 만큼 위에 있다. 6보다 가까워질수록 높이 비율은 0.7 → 0.12, 시선은 키의 0.55 → 0.88(얼굴)로 부드럽게(smoothstep) 옮겨 가서, 가장 가까이 당기면 얼굴 높이에서 살짝 위에서 본다. 키 배율(0.75~1.3)에 맞춰 높이를 잡는다.
- 카메라 수평 위치는 플레이어에 바로 붙고(가까이 당긴 채 카메라 쪽으로 걸어도 몸을 뚫지 않게), 방향·거리·높이만 부드럽게 따라간다.
- 탐험 중 거리 3보다 가깝고 0.4초 넘게 멈춰 있으면 캐릭터가 카메라 쪽으로 천천히 돌아선다(카메라는 돌리지 않는다). 낚시 중이 아니면 거리 3보다 가까울 때 낚싯대를 숨긴다.
- 탐험·낚시·휴식 중에 동작하고, 패널(상점·도감·꾸미기 등)이 열려 있으면 휠은 패널 스크롤에 쓴다.
- 브라우저 페이지가 같이 스크롤되지 않게 캔버스에서 휠 기본 동작을 막는다.
- 줌 값은 저장하지 않는다.

## 8. 데이터·코드 구조

```
tools/build-characters/      팩 받기·합치기·다듬기 스크립트 (+ package.json)
public/models/characters/    male.glb, female.glb
src/game/
  data/characterParts.ts     성별별 부위 목록, 메시 이름, 견본 색, 키·몸 부위 범위, 기본 꾸밈
  data/characters.ts         (수정) 클립 표 + 앉기 클립, 성별 → 파일
  data/types.ts              (수정) CharacterLook
  logic/characterLook.ts     모습 검증·보정, 성별 바꿀 때 부위 맞추기, 랜덤 (+ test)
  logic/characterPose.ts     (수정) 앉기 자세 (+ test)
  logic/cameraZoom.ts        휠 → 거리 계산, 범위 제한 (+ test)
  stores/progressStore.ts    (수정) look 저장 + 불러올 때 검증 (+ test)
  logic/interaction.ts       (수정) wardrobe 대상·모드 (+ test)
  scene/characterLook.ts     모습 적용(부위·색·텍스처·뼈 배율)
  scene/PlayerModel.tsx      (수정) look 반영, 앉기
  scene/Player.tsx           (수정) 벤치 자리로 옮기기, 휠 줌
  scene/facilities/Wardrobe.tsx
  ui/CharacterCreator.tsx    꾸미기 화면 (+ 미리보기 Canvas)
```

- 층 규칙(scene/ui → stores → logic → data)과 "밸런스·범위 값은 data에만"을 지킨다.
- 저장 키·버전(`fishing-island-save-v1`, version 1)은 그대로, 새 필드 `look`은 merge에서 검증한다.

## 9. 테스트

- `characterLook`: 범위 밖 값 보정, 없는 부위 → 기본값, 성별 바꿀 때 부위 맞추기, 랜덤 결과가 항상 유효, 기본 꾸밈이 모두 유효
- `cameraZoom`: 휠 방향, 최소·최대 제한
- `characterPose`: 휴식 중 앉기 자세, 일어날 때 자세
- `progressStore`: look이 없는 저장본, 깨진 look 저장본
- `interaction`: 옷장 E, 꾸미기 화면에서 ESC 동작(첫 생성 땐 닫히지 않음)
- 화면 확인(headless 캡처): 남녀 기본 꾸밈, 부위 바꾸기, 피부·머리색 양 끝, 키·몸 부위 슬라이더 양 끝(다리 길이를 바꿔도 발이 땅에 닿는지), 벤치에 앉은 모습, 줌 가까이·멀리, 남녀 각각 낚시 반응(끌려가기·춤·벌러덩)

## 10. 범위 밖

- 쓰러질 때 넘어지는 연출(별도로 다룬다)
- 모자·안경 같은 추가 장신구, 낚싯대 스킨(2차)
- 다른 팩의 옷 추가(부위 목록 구조만 늘릴 수 있게 둔다)
- 터치 핀치 줌
