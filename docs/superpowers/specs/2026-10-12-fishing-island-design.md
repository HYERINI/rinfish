# 낚시섬 (가제) — 설계 문서

- 작성일: 2026-10-12
- 상태: 사용자 리뷰 대기
- 범위: 1차 개발 (2차 항목은 마지막 섹션에 별도 정리)

## 1. 개요

팀 공용 로비에서 진입하는 3D 낚시 게임. 플레이어는 꾸민 캐릭터로 섬을 3인칭으로 걸어 다니며 낚시 포인트를 찾고, 개성 있는 물고기를 잡아 **팔거나(코인) / 먹거나(체력·버프) / 어항에 전시(관람객 수입)** 하며 장비를 키운다. 최종 목표는 동굴 지하호수의 **전설의 물고기**를 잡는 것.

- 레퍼런스: Steam 게임 *How to Fish* — 가져올 요소는 **개성 있는 물고기, 낚는 손맛, 성장감**
- 목표 플레이 타임: 첫 클리어까지 15~20분
- 플랫폼: 데스크톱 브라우저, 키보드 + 마우스

### 가정 (변경 가능)
- 저장은 브라우저 localStorage만 사용, 서버 없음
- 3D 모델은 무료 에셋(Quaternius, Kenney 등) 사용, 개발 초기에는 기본 도형으로 대체

## 2. 기술 스택 및 로비 연동

- Vite + React + TypeScript
- three, @react-three/fiber, @react-three/drei
- @react-three/rapier (이동·충돌·영역 감지)
- zustand (+ persist 미들웨어)
- vitest (순수 로직 테스트)

### 로비 연동 계약
게임 전체는 `src/game/Game.tsx`의 단일 컴포넌트로 노출한다.

```ts
type GameProps = {
  onExit?: () => void                         // ESC 메뉴 "로비로 나가기"
  onFinish?: (result: { score: number }) => void  // 첫 클리어 시 1회 호출
}
```

- 게임은 부모 요소 크기를 100% 채운다.
- 진행 상황은 localStorage에 저장되므로 로비로 나갔다 돌아와도 이어서 플레이한다.

## 3. 핵심 루프

```
섬 탐험 → 낚시 포인트에서 E → 캐스팅 → 입질 타이밍 → 텐션 줄다리기
  → 물고기 획득(카드 팝업, 도감 등록)
  → [판매 → 코인 → 장비 업그레이드 / 구역 해금 / 사료 구매]
    [어시장 → 요리 → 체력 회복 + 버프]
    [어항 전시 → 관람객 수입]
  → 더 강한 물고기 → … → 전설의 물고기 → 엔딩
```

## 4. 낚시 미니게임

### 4.1 캐스팅
- 마우스를 누르고 있는 시간으로 던지는 거리를 정한다. 거리에 따라 걸리는 물고기 풀이 조금 달라진다(먼 곳일수록 희귀도 가중치 증가).
- 캐스팅마다 체력을 소모한다.

### 4.2 입질
- 찌가 몇 번 톡톡 흔들리다(페이크) 크게 잠기는 순간 클릭하면 훅셋 성공.
- 반응 허용 시간을 놓치면 물고기가 도망간다.

### 4.3 텐션 줄다리기 (A안 확정)
- **마우스 누름** = 릴 감기: 거리가 줄고 텐션이 오른다.
- **뗌** = 줄 풀기: 텐션이 내려가고 거리가 조금 늘어난다.
- 텐션이 **최대치를 넘으면 줄이 끊김**(실패), **0 근처에 일정 시간 머무르면 바늘이 빠짐**(실패).
- 거리가 0에 도달하면 성공.
- 물고기는 **성격 패턴**에 따라 주기적으로 저항(텐션 급상승, 거리 증가)한다.

| 패턴 | 동작 |
|---|---|
| 돌진형 | 짧고 강한 저항이 드물게 발생 |
| 지구전형 | 약한 저항이 길게 지속 |
| 변덕형 | 저항 타이밍·세기가 불규칙 |
| (전설) 혼합형 | 위 세 패턴을 페이즈별로 전환 |

- 줄다리기 중 체력이 초당 소모되며, 물고기 힘이 셀수록 소모량이 커진다.
- 3D 연출: 낚싯대 휘어짐, 줄 떨림, 물보라, 물고기 그림자 움직임. HTML 텐션 게이지를 함께 표시한다.

### 4.4 장비 효과
| 장비 | 미니게임 영향 |
|---|---|
| 낚싯줄 | 최대 텐션(끊김 한계) 증가 |
| 릴 | 감기 속도 증가 |
| 낚싯대 | 물고기 저항 시 텐션 상승폭 완화 |

각 장비 3단계(기본 포함 Lv1~Lv3), 코인으로 구매한다. **장비를 최고 단계까지 올려도 게임은 끝나지 않는다** — 종료 조건은 전설의 물고기뿐이다.

## 5. 물고기

- 일반 물고기 약 12종(구역당 3~4종) + 전설 1종
- 희귀도: 일반 / 희귀 / 에픽 / 전설
- 종(species) 정의 필드: `id, name, description, zone, rarity, pattern, strength, weightRange, basePrice`
- 같은 종이라도 개체마다 **무게가 랜덤**이며, 판매가는 무게에 비례한다.
- 예시: 졸린 정어리(일반·지구전), 선글라스 고등어(희귀·돌진), 개굴 메기(일반·변덕), 해적 참치(에픽·돌진), 왕관 쓴 황금 잉어(전설·혼합)
- **잡어**: 낮은 확률로 걸리는 판매가가 매우 낮은 물고기. 어항 먹이로 사용 가능.
- 도감: 종별 최초 포획 여부와 최대 무게 기록.

### 물고기 개체 데이터
보유 물고기는 종별 개수가 아니라 **개체 단위**로 저장한다. 판매·요리·전시가 모두 같은 데이터를 다룬다.

```ts
type FishInstance = {
  id: string
  speciesId: string
  weight: number
  caughtAtPlayTime: number
  lastFedAtPlayTime?: number   // 어항 전시 중일 때만 사용
  hungrySincePlayTime?: number
}
```

보관함(인벤토리) 칸 수 제한은 1차에서 두지 않는다.

## 6. 섬과 구역

| 구역 | 해금 조건 | 특징 |
|---|---|---|
| ① 선착장 해변 | 기본 | 시설 밀집 지역(판매함, 장비 상점, 어시장, 진료소, 벤치, 어항) |
| ② 숲속 연못 | 코인으로 다리 수리 | 민물 어종 |
| ③ 암초 앞바다 | 코인으로 보트 수리 | 강한 어종 |
| ④ 동굴 지하호수 | 도감 8종 이상 + 낚싯줄 Lv3 | 전설의 물고기 |

- 이동: WASD + 3인칭 추적 카메라. 마우스로 카메라 회전.
- 잠긴 구역은 충돌체(무너진 다리, 부서진 보트 등)로 막고, 해금 시 충돌체를 제거하거나 교체한다.
- 낚시 포인트와 시설은 Rapier 센서 영역으로 감지하고, 진입하면 "E: 낚시" 같은 안내를 띄운다.

## 7. 체력과 어시장

### 7.1 체력
- 최대 100(초기값). 캐스팅마다 소모, 줄다리기 중 초당 소모.
- **체력 0** → **약화 상태로 3분 유예**
  - 화면 가장자리 붉은 효과, 심장 소리, 남은 시간 카운트다운
  - 낚시는 가능하지만 릴 속도 감소, 저항 시 텐션 상승폭 증가
  - 유예 중 체력을 회복하면 정상 상태로 복귀
- **유예 시간 종료 → 쓰러짐**
  - 선착장 진료소에서 깨어남
  - **팔지 않은 보유 물고기 전부 상실**(어항에 전시 중인 물고기는 유지)
  - 보유 코인의 일부를 진료비로 차감(초기값 20%)
  - 장비, 도감, 해금 상태는 유지
- **벤치 휴식**: 선착장 벤치에 앉으면 체력이 천천히 회복된다. 코인과 물고기가 모두 없어도 막히지 않게 하는 안전장치.

### 7.2 어시장 요리
물고기 1마리 + 소액 조리비로 요리를 사 먹는다. 희귀도가 높은 물고기로 만들수록 효과가 강하다.

| 요리 | 효과 |
|---|---|
| 회 | 체력 회복 |
| 회덮밥 | 체력 회복 + 일정 시간 릴 속도 증가 |
| 매운탕 | 체력 크게 회복 + 일정 시간 텐션 상승 완화 |

버프는 같은 종류끼리 중첩되지 않고 지속시간만 갱신된다.

## 8. 어항 (어시장 밖)

- 어시장 옆 어항에 보유 물고기를 전시한다. 전시된 물고기는 어항 안에서 3D로 헤엄친다.
- 전시를 해제하면 다시 보유함으로 돌아온다.
- **관람객 수입**: 전시 중인 물고기의 희귀도에 따라 구경꾼이 모이고, 플레이 시간에 비례해 입장료 코인이 쌓인다. 어항 앞에서 수령한다.

### 8.1 어항 확장 (코인)
어항을 키울수록 칸 수가 늘고 입장료 배율이 오른다. 확장하면 3D 어항 모델 크기도 커진다.

| 단계 | 칸 수 | 입장료 배율 |
|---|---|---|
| Lv1 (기본) | 6 | ×1.0 |
| Lv2 | 9 | ×1.2 |
| Lv3 | 12 | ×1.5 |

### 8.2 어항 종류 (코인으로 구매, 언제든 교체)
어항 종류마다 어울리는 물고기가 있어 **해당 구역 물고기를 전시하면 수입 보너스**(초기값 +50%)가 붙는다. 구매한 종류는 계속 보유하며 교체 비용은 없다.

| 종류 | 보너스 대상 | 외형 |
|---|---|---|
| 기본 유리 어항 | 없음 | 투명 유리, 모래 바닥 |
| 바다 수조 | ① 선착장 해변, ③ 암초 앞바다 | 파란 물, 산호 |
| 민물 수조 | ② 숲속 연못 | 초록 물, 수초·돌 |
| 동굴 수조 | ④ 동굴 지하호수 | 어두운 물, 발광 이끼 |

어항 종류와 확장 단계는 서로 독립적이다(어떤 종류든 확장 단계가 그대로 적용).
- **먹이**: 장비 상점의 사료(코인 구매) 또는 잡어를 준다. 먹이를 주면 물고기들이 몰려와 먹는 연출이 나온다.
- **배고픔** (플레이 시간 기준, 로비에 나가 있는 동안에는 흐르지 않음)

| 단계 | 조건 | 결과 |
|---|---|---|
| 배고픔 | 마지막 급식 후 10분 | 바닥에 가라앉고 수입 정지. 급식하면 즉시 회복 |
| 방생 | 배고픔 상태로 10분 더 방치 | 바다로 돌아가 어항에서 사라짐(도감 기록은 유지) |

- 배고픔 진입 시, 방생 2분 전에 화면 알림을 띄운다.

## 9. 경제 요약

| 수입 | 지출 |
|---|---|
| 물고기 판매(무게 비례) | 장비 업그레이드 |
| 어항 관람객 수입 | 구역 해금(다리·보트 수리) |
| | 어항 확장, 어항 종류 구매 |
| | 요리 조리비, 사료 |
| | 쓰러짐 진료비 |

모든 수치(가격, 체력 소모량, 버프 효과, 시간 값)는 `src/game/data/`의 데이터 파일에서만 조정한다.

## 10. 진행·엔딩

- 화면 흐름: `타이틀 → (최초) 캐릭터 선택 → 섬 탐험 ⇄ 낚시 / 상점 / 어시장 / 어항 / 도감 → 엔딩`
- 전설의 물고기 포획 시 엔딩 연출 후 `onFinish({ score })` 호출. **최초 클리어 시 1회만 호출**한다.
- 점수: 클리어까지 걸린 플레이 시간 기반(빠를수록 높음).
- 엔딩 후 "계속 낚시하기"로 자유 플레이(도감 채우기, 큰 개체 노리기) 가능.
- ESC 메뉴: 계속하기 / 도감 / 로비로 나가기(`onExit`).

## 11. 캐릭터 (1차)

- 낚시꾼 캐릭터 **종류 선택**(예: 고양이, 펭귄, 사람 등 무료 에셋에서 애니메이션이 있는 모델) + **색상 변경**
- 최초 시작 시 선택하며, 선착장의 거울(또는 옷장)에서 언제든 변경한다.

## 12. 코드 구조

```
src/game/
  Game.tsx              # 로비 연동 진입점
  data/                 # fish, gear, dishes, zones, balance(시간·체력 수치)
  logic/                # 순수 함수 + vitest 테스트
    fight.ts            #   텐션 줄다리기 스텝 함수 stepFight(state, input, dt)
    bite.ts             #   입질 타이밍
    stamina.ts          #   체력·유예·쓰러짐
    economy.ts          #   판매가, 구매, 진료비
    cooking.ts          #   요리 효과
    aquarium.ts         #   관람객 수입(확장 배율·종류 보너스), 배고픔, 방생
    catchTable.ts       #   구역·거리별 물고기 추첨
  stores/
    progressStore.ts    # 저장 대상: 코인, 장비, 보유 물고기, 도감, 해금, 어항, 캐릭터, 플레이 시간, 클리어 기록
    sessionStore.ts     # 비저장: 현재 체력, 유예 타이머, 현재 모드, 활성 버프, 진행 중인 낚시 상태
  scene/
    Island.tsx          # 지형, 물, 구역 경계, 잠긴 길
    Player.tsx          # 캐릭터 이동, 3인칭 카메라
    fishing/            # 찌, 낚싯줄, 낚싯대 연출
    facilities/         # 판매함, 상점, 어시장, 진료소, 벤치, 어항(3D + 센서 영역)
  ui/                   # HUD, 텐션 게이지, 각종 패널, 캐릭터 선택, 엔딩, ESC 메뉴, 알림
```

### 원칙
- **게임 규칙은 `logic/`의 순수 함수**로 작성하고 React/Three.js에 의존하지 않는다. 3D/UI 컴포넌트는 결과값을 받아 표현만 한다.
- 시간 기반 규칙(유예, 배고픔, 버프, 관람객 수입)은 실제 시각이 아니라 **누적 플레이 시간**(`progressStore.playTime`)을 기준으로 한다.
- localStorage 저장 키에는 버전을 붙인다(예: `fishing-island-save-v1`).

## 13. 테스트

- `logic/` 전 모듈은 vitest 단위 테스트로 검증한다. 예:
  - 텐션이 한계를 넘으면 줄이 끊긴다
  - 낚싯줄 Lv3는 Lv1보다 한계가 높다
  - 체력 0 후 3분이 지나면 쓰러짐 상태가 되고 보유 물고기가 비워진다
  - 배고픈 물고기는 수입을 내지 않고, 10분 더 지나면 방생된다
- 3D·UI는 브라우저에서 직접 플레이하며 확인한다.

## 14. 개발 순서

1. 섬 + 플레이어 이동 (도형)
2. 낚시 미니게임 (캐스팅·입질·줄다리기)
3. 물고기 데이터 + 도감
4. 판매 + 장비 상점
